# The present and future distribution of permafrost-affected lakes 
Companion code to the journal article "The present and future distribution of permafrost-affected lakes." 

This repository is organized into folders as follows:

`Data curation` contains the code to curate the data underpinning the analyses. Note that code used to create lake density and lake coverage dataets are archived along with the the generated data at: XXXXXXX (ADC LINK)

`Tables` contains the code to generate Table 1, Table 2, and determine the area covered by each landscape class.

`Figures` contains the code to generate Figures 1-5, 6-7.
